# Poster Library（ポスター管理アプリ）

制作したポスターの印刷データを、カテゴリー別に一覧・保存・ダウンロードできるアプリです。
Windows 標準の PowerShell だけで動くので、追加のインストールは不要です。

## 起動

1. `start.bat` をダブルクリック
2. ブラウザで http://localhost:8765/ が開きます
3. 終了するときは黒いウィンドウを閉じます

## 画面

| ページ | URL | できること |
|---|---|---|
| ポスター一覧 | `/` | カテゴリー別の一覧表示、検索、並べ替え、詳細表示、ダウンロード、アップロード |
| 管理ページ | `/admin` | カテゴリーの追加・名前変更・並べ替え・削除、ポスターの編集・印刷データの差し替え・サムネイル変更・削除 |

- サムネイルは PDF / AI（PDF互換保存）/ 画像ファイルから自動で作成されます（インターネット接続が必要）。
  PSD などは「サムネイル画像を指定」で JPG/PNG を選んでください。
- カテゴリーを削除すると、そのカテゴリーのポスターは「未分類」になります（ポスターは消えません）。

## データの保存場所

```
data/db.json   … タイトル・カテゴリーなどの情報
data/files/    … 印刷データ本体
data/thumbs/   … サムネイル画像
```

バックアップは `data` フォルダをまるごとコピーしてください。
